# Click & Earn API

This Laravel application is the backend for the repository-root Click & Earn frontend. Follow the root [README](../README.md) for local setup, isolated test-database requirements, queue/scheduler operation, and the Phase 2 production-configuration gate.

Keep database, mail, storage, and payout credentials in the backend environment only. The local seeder is fictional development data and refuses to run in production. Do not bypass the test database guard or point tests at an application database.
